✦ Meet the Agents

6 Specialised AI Agents,
Working Together 24/7

RecoverAI is not one AI — it's an orchestrated fleet of specialised agents, each with a precise responsibility in the recovery pipeline.

Agent 01
📬
IMAP Parser Agent
Email Ingestion
Autonomously connects to your Gmail or any IMAP mailbox every 15 minutes via SSL. Scans all unread emails, extracts PDF invoice attachments, verifies the sender is a registered user (zero-trust), and passes raw PDF bytes downstream.

Tech: imaplib + asyncio.to_thread
IMAP/SSL Multi-tenant Async
Agent 02
📄
Gemini Extraction Agent
PDF Intelligence
Sends raw PDF bytes to Gemini 2.0 Flash as an inline blob (no temp files). Extracts 10 structured fields: debtor name, amount, due date, GSTIN, invoice number, PO number, email, phone, and notes. Prompt-injection hardened with strict rule set.

Output: Validated InvoiceCreate Pydantic model
Gemini 2.0 Flash JSON Schema XSS Safe
Agent 03
🗄️
MongoDB Insertion Agent
Idempotent Storage
Idempotent upsert engine — checks email_ingestion_log for the exact (message_id, filename) pair before every insert. Ensures zero duplicate invoices no matter how many times the ingester runs. Assigns invoices to the correct tenant account automatically.

Tech: Motor async + MongoDB compound index
Idempotent Motor Async Multi-tenant
Agent 04
🌐
NLP Translation Agent
Multilingual Understanding
Translates debtor WhatsApp replies from Hindi, Hinglish, Marathi, Tamil, Telugu, Gujarati, Bengali, Punjabi into clean professional English. If the Gemini API quota is hit, it falls back to a local keyword heuristic that covers 30+ Hindi/Hinglish payment terms (kal, bhej, deta, galat, etc.) — zero downtime.
8+ Languages Heuristic Fallback Zero Downtime
Agent 05
🎯
Intent Classification Agent
Reply Intelligence
Classifies the translated reply into one of four intents: promise_to_pay, dispute, stall, or unknown. Returns confidence level (high / medium / low) and a precise suggested action. Responds with a structured JSON object — validated against schema before use.
4 Intent Classes JSON Schema Confidence Score
Agent 06
🤖
AI Message Generation Agent
Recovery Drafting
Drafts WhatsApp messages, formal emails, and MSMED Act legal notices using a 3-tier Gemini model cascade: Gemini 2.0 Flash → Gemini 2.5 Flash → Gemini 1.5 Flash. Supports tone settings (firm / empathetic / legal). Generates full messages with context from invoice data including overdue days and MSMED compound interest.
3-Model Cascade WhatsApp + Email MSMED Legal

✦ Enterprise Security

Production-Grade Security,
Out of the Box

RecoverAI was built with a full security audit — protecting your financial data with layers of hardened defences.

🔐
Brute Force Protection
IP-based rate limiter locks out after 5 failed login attempts in 15 minutes. Spoofing-resistant X-Forwarded-For parsing.
💉
NoSQL Injection Shield
Recursive payload sanitisation strips all MongoDB operators ($) from user inputs. Protected field blocklist prevents privilege escalation.
🛡️
SSRF Protection
URL parser blocks requests to private IP ranges (RFC 1918, RFC 3927), cloud metadata endpoints, and localhost — preventing server-side request forgery.
📁
Secure File Uploads
MIME type + extension allowlist. UUID-renamed files eliminate path traversal. 10MB chunk-based size limit against DoS.
🔑
JWT Token Revocation
In-memory JTI blacklist immediately invalidates access tokens on logout — preventing token reuse attacks even before expiry.
📋
Security Headers
HSTS, CSP, X-Frame-Options, X-XSS-Protection injected on every response. Server fingerprinting stripped from all HTTP headers.
📝
Audit Logging
Structured access log captures HTTP method, path, IP, latency, and status code for every request — full forensic trail.
🔒
HMAC Webhook Verification
WhatsApp webhook payloads are verified via X-Hub-Signature-256 HMAC before processing — rejecting forged Meta callbacks.

Vercel Serverless

JWT + Passlib + Jose
Industry-standard JWT authentication with bcrypt password hashing. Token revocation via JTI blacklist. Strong password policy enforced server-side.
